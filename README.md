# DevOps Portfolio - CI/CD Pipeline

[![CI/CD](https://github.com/saramsuDevOps/devops-portfolio/actions/workflows/deploy.yml/badge.svg)](https://github.com/saramsuDevOps/devops-portfolio/actions/workflows/deploy.yml)
[![Docker Hub](https://img.shields.io/badge/Docker%20Hub-saramsudevops%2Fdevops--portfolio-blue)](https://hub.docker.com/r/saramsudevops/devops-portfolio)

A containerized Node.js application with automated CI/CD pipeline deploying to Docker Hub.

## Features

- **Containerization**: Docker with multi-stage build optimization
- **Orchestration**: Docker Compose for local development
- **CI/CD Pipeline**: GitHub Actions automating build and push to Docker Hub
- **Health Checks**: Automated container health monitoring
- **Security**: Secrets management for credentials

## Tech Stack

| Category | Tools |
|----------|-------|
| Runtime | Node.js 18 |
| Container | Docker |
| Orchestration | Docker Compose |
| CI/CD | GitHub Actions |
| Registry | Docker Hub |
